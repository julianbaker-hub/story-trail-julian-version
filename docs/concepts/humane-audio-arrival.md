# Humane audio arrival

Automatic audio is valuable only when it feels like the continuation of the walk. Surprise playback, abrupt switching,
or unexplained silence breaks trust faster than requiring one tap.

## Arrival policy

When a person enters a stop:

1. Select the arrived stop and mark it visited.
2. If the person deliberately started the tour or audio is already playing, continue with the new story.
3. Otherwise, announce the arrival without starting sound.
4. Show a brief, accessible confirmation and preserve normal playback controls.

This policy interprets current behavior as intent. It does not assume that opening a map grants permission for audio to
start later.

## Interruptions and recovery

Pause for system interruptions, retain the current stop and position, and make resumption explicit when intent is
unclear. Failed downloads should keep the transcript and route available. A retry belongs beside the player error, not
in a modal that blocks the walk.
